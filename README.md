# 📈 像素股神模擬器 — 規格書

🔗 線上遊玩：https://fylel.github.io/pixel-stock/

## 1. 發想過程
- 想做「股市相關」的網頁，風格希望是「復古像素風」。
- 和 AI 討論後的候選方向：像素股神模擬器、漲跌猜猜看、存股小豬計算器、復古股票終端機。
- 考量 GitHub Pages 只能放靜態網頁，抓即時股價需要 API 金鑰容易卡關，因此改用**程式自行產生的模擬股市**。
- 最後選擇「像素股神模擬器」：有遊戲性，也最能展現像素風。

## 2. 作品概述
| 項目 | 內容 |
|---|---|
| 名稱 | 像素股神模擬器 |
| 類型 | 股市模擬小遊戲 |
| 技術 | 單一 `index.html`（HTML + CSS + JavaScript），無需後端 |
| 目標 | 在 30 天內透過買賣虛構股票，讓總資產越多越好 |

## 3. 遊戲規則
- 初始資金 **$10,000**，遊戲共 **30 天**。
- 市場有 5 檔虛構股票：珍奶科技、雞排半導體、鹹酥雞航運、滷味金控、夜市電動車。
- 每檔股票有不同的波動程度，每天股價隨機漲跌。
- 每天有 **40%** 機率發生新聞事件，讓某一檔股票大漲或大跌（例如「發表新產品」+15%、「財報造假疑雲」−18%）。

## 4. 功能清單
1. **資訊列**：顯示目前天數、現金、總資產（現金＋持股市值）。
2. **股票列表**：顯示股名、股價、當日漲跌幅（▲紅漲 ▼綠跌）、持有股數；點選可切換股票。
3. **像素走勢圖**：以方塊長條畫出選中股票的歷史股價，漲為紅、跌為綠。
4. **交易**：輸入數量後按「買進」或「賣出」；現金或持股不足時會出現提示。
5. **時間控制**：
   - ▶ 開始／⏸ 暫停：自動播放，每 2.5 秒過一天
   - ⏭ 下一天：手動前進一天
   - 🔄 重新開始
6. **市場新聞欄**：顯示新聞事件與交易紀錄，最新的在最上面。
7. **結算畫面**：第 30 天結束時顯示最終資產、報酬率與稱號。

| 報酬率 | 稱號 |
|---|---|
| ≥ 50% | 👑 股神 |
| ≥ 15% | 😎 高手 |
| ≥ 0% | 🙂 散戶 |
| < 0% | 🥬 韭菜 |

## 5. 畫面配置
```
┌──────────────── 📈 像素股神模擬器 📉 ────────────────┐
│ 📅 第 N / 30 天     💰 現金       🏦 總資產          │
├──────────────────────┬──────────────────────────────┤
│ 股票列表             │ 走勢圖                        │
│ （點選切換）          │ 數量 [  ] [買進] [賣出]       │
├──────────────────────┴──────────────────────────────┤
│ [▶ 開始] [⏭ 下一天] [🔄 重新開始]                    │
├─────────────────────────────────────────────────────┤
│ 📰 市場新聞                                          │
└─────────────────────────────────────────────────────┘
```
手機寬度（< 700px）時，股票列表與走勢圖改為上下排列。

## 6. 視覺風格
- 復古 8-bit 像素風，字型使用像素字體 DotGothic16。
- 深藍色背景、藍色粗邊框、黑色方塊陰影。
- 黃色標題搭配粉紅色陰影；按鈕按下時有「壓下去」的效果。
- 漲為紅色、跌為綠色（台股慣例）。

## 7. 開發與測試
- 以 Vibe Coding 方式與 AI 對話完成程式。
- 修正過的問題：走勢圖公式括號錯誤導致長條畫在畫布外，已修正。
- 已測試：開局、買進、賣出、餘額不足提示、切換股票、下一天、走勢圖、開始／暫停、30 天結算、結束後禁止交易、重新開始，皆正常運作。
